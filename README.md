# IRON RECON: CO-OP RUN & GUN — 2-Player Tactical Shooter

A gritty, realistic military side-scrolling co-op run & gun arcade shooter inspired by modern tactical operations and classic run-and-gun arcade classics.

## What Makes It Real

### 1. Realistic Operators ("Real Men")
- **Player 1: SGT. STONE (Assault Operator)**
  - Detailed crye multicam tactical fatigues, FAST ballistic helmet with night-vision shroud, tactical eye goggles, heavy plate carrier with MOLLE magazine pouches, utility thigh holster, rugged bearded jawline, and tactical combat boots with tread.
  - Two-handed firearm manipulation with visible trigger hand and support hand on handguard.
- **Player 2: CPT. VANCE (Spec-Ops Commando)**
  - Urban shadow-grey tactical loadout, skull-print balaclava face mask, comms headset with active radio boom mic, carbon-knuckle combat gloves, and reinforced tactical boots.
- **Realistic Combat Mechanics**:
  - Point-blank range automatically executes a swift **KA-BAR Combat Knife Takedown (+500pts)** with dynamic arterial blood mist and audio slice.
  - Active red tactical laser aiming sights projecting from firearm barrels.
  - Realistic recoil physics: gun cycles backward and pushes the operator's arms back with every shot.
  - Dynamic muzzle flash illuminating the operator and environment.
  - Physics-driven brass 5.56mm and red 12-gauge shotgun shell casings that eject into the air, tumble, bounce off the ground, and ping on hard surfaces.
  - Persistent blood stains and decals on the ground after hostile eliminations.

### 2. Realistic Hostiles ("Real Enemies")
- **Insurgent AK-47 Riflemen**: Guerrilla fighters in desert/forest fatigues with shemagh headwraps and curved magazine Kalashnikovs.
- **Heavy Ballistic Riot Shield Infantry**: Advancing behind thick steel ballistic shields with transparent bulletproof viewports; impervious to frontal 5.56mm fire unless flanked, sniped, or neutralized with explosives/shotgun blasts.
- **Ghillie Suit Snipers**: Camouflaged marksmen aiming high-powered precision rifles with visible red laser targeting lines.
- **RPG-7 Operators**: Shoulder-mounted anti-tank rocketeers firing high-explosive rocket-propelled grenades with exhaust backblast.
- **Mil Mi-24 Style Attack Gunships**: Twin-turbine attack helicopters strafing with 30mm chain guns and dropping payload bombs.
- **Heavy War Machines (Bosses)**:
  - **Operation 1**: Corvette Warship "Tetsuyuki" with dual naval deck cannons.
  - **Operation 2**: Siege Fortress "Iron Nokana" multi-turret heavy tank.
  - **Operation 3**: Twin-Turbine Sky Gunship "Hi-Do".
  - **Operation 4**: Bipedal Apex War Mech "Jupiter King".

### 3. Real Firearms Arsenal
- **M4A1 SOPMOD Carbine**: Standard-issue 5.56x45mm NATO rifle with full-auto capability, holographic optic, and brass casing ejection.
- **Benelli M4 Tactical Shotgun**: 12-gauge buckshot tearing through barricades and shields with flying red shells.
- **Barrett .50 Anti-Materiel Rifle**: High-caliber armor-piercing supersonic rounds that over-penetrate multiple enemies in a straight line.
- **M249 SAW Light Machine Gun**: Belt-fed suppression with continuous tracer spray.
- **RPG-7 Anti-Armor Rocket**: Shoulder-fired conical rocket warhead with smoke plume and wide-radius blast crater.
- **M67 Fragmentation Grenades**: High-explosive pineapple frag grenades.
- **M2 Bradley Combat Tank**: Boardable armored combat vehicle with 25mm Bushmaster autocannon and armor-piercing main gun.

## Controls
| Action | Player 1 (Sgt. Stone) | Player 2 (Cpt. Vance) |
| :--- | :--- | :--- |
| **Move Left / Right** | <kbd>A</kbd> / <kbd>D</kbd> | <kbd>←</kbd> / <kbd>→</kbd> |
| **Aim Upwards** | <kbd>W</kbd> | <kbd>↑</kbd> |
| **Duck / Crawl** | <kbd>S</kbd> | <kbd>↓</kbd> |
| **Fire Weapon / KA-BAR Knife** | <kbd>J</kbd> | <kbd>/</kbd> or <kbd>Z</kbd> |
| **Combat Jump / Mount Tank** | <kbd>K</kbd> or <kbd>Space</kbd> | <kbd>Enter</kbd> or <kbd>X</kbd> |
| **M67 Frag Grenade** | <kbd>L</kbd> | <kbd>.</kbd> or <kbd>C</kbd> |

- **Touchscreen**: On-screen tactical D-pad and action buttons automatically enabled on mobile/tablet (toggle with 📱 button).
- **Dual Gamepad Support**: Plug-and-play for 2 USB / Bluetooth controllers.
- **CRT Monitor Filter**: Toggleable scanline filter (🖥️ button).
